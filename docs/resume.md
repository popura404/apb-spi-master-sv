# 简历与面试准备

项目名称可以使用：**基于 APB3 的可配置 SPI 主机 IP 设计与验证**。
下列技术描述对应当前工程的实际功能和测量值；“负责”的范围按你后续实际理解、
修改和验证的工作填写。

## 项目描述参考

- 使用 SystemVerilog 实现 APB3 外设控制器，支持 SPI 四种模式、MSB/LSB 位序、可配置
  时钟分频、1～4 路片选、独立收发 FIFO 和完成/错误中断。
- 实现多字节连续片选事务，支持 FIFO 缺数据/缺空间时在字节边界暂停，提供
  非法访问响应、传输中止及复位恢复机制。
- 搭建 APB 激励与独立 SPI 从机自检查环境，完成 7 组 Icarus 回归；覆盖模式、
  位序、分频、FIFO 边界、中断同周期竞争及异常恢复，并通过 Vivado XSim。
- 在 xc7z020clg400-1 上完成 IP 独立综合和布局布线，默认配置使用 285 LUT、
  142 FF；100 MHz 内部时钟约束下建立裕量 2.421 ns、保持裕量 0.034 ns。

简历篇幅有限时选三条即可。最后一条要保留“IP 独立”和“内部时钟”限定，避免
把未完成的板级实现、PS 集成或实测 SPI 速率混进结果。

## 建议能讲清楚的八个问题

1. APB 为什么不能在 PSEL 一拉高时就把 TXDATA 写入 FIFO？
2. CPHA=0 与 CPHA=1 的首位准备和最后一位采样有何区别？
3. 为什么所有逻辑使用 PCLK，SCLK 只作为输出？
4. 为什么开始一个字节之前就要检查 RX 空间？
5. 写 TX 满、读 RX 空时，为什么选择报错而非一直拉低 PREADY？
6. 软件 W1C 恰好与新 DONE 同拍时，应该保留哪一个效果？
7. 为什么 FIFO 存储阵列不需要整体复位，怎样让 Vivado 推断 RAM？
8. 当前 WNS 为正证明了什么，又有哪些外部时序尚未检查？

## 做成自己的项目

建议挑一个有明确指标的扩展：

- **减少字节间空隙：**测量相同 PCLK/DIVIDER 下的持续字节吞吐率，保留前后
  波形和资源报告，特别检查 CPHA=0 首位与 RX 入队时刻。
- **增加 RX 水位中断：**定义水位寄存器、触发/清除规则，验证临界计数与同拍
  push/pop，比较软件轮询次数。
- **接入自己的 Zynq 板：**增加桥接与 PS 驱动，连接一个已知 SPI 器件，记录
  示波器/逻辑分析仪测量和读写结果。

每个扩展都先定义行为，再实现、验证和测量；完成一个能够解释清楚的改进，比
只在项目标题里继续堆功能更容易形成有内容的面试讨论。
